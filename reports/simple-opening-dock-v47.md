# 简洁模式：棋盘边缘开局操作

版本：2026.10.18.2 / v47。基于 main `124ad0703a3643aaf9ef24ac0f920a06c75f46a2`。

换手、十打路线、第五手候选、开局角色与禁手确认现在紧贴棋盘边缘。宽窗口放在棋盘侧边，窄窗口放在上沿；简洁模式收起长说明，保留当前阶段和原有操作按钮。按钮触摸高度至少 44px。

操作区在 SVG 之外。棋盘与操作区共同使用原有独立尺寸槽，先预留按钮空间，再确定棋盘大小与位置，二者之间保留 6px；不会用覆盖交叉点的方式换取空间。没有可点操作时仅显示简短阶段信息。极小窗口的规则选择菜单可在自身内部滚动，普通换手和候选操作无需滚动。

完整模式恢复原有棋盘居中布局；继续复用原开局状态、事件处理与自动应手。未修改执色归属、规则、搜索预算、推荐点逻辑或远程引擎协议。尺寸变化保留亚像素容差，避免横竖屏切换后反复改写棋盘大小。
