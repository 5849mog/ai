# 三色棋盘候选

版本 `2026.10.15.2`，页面缓存 v42。基线 `4e38987911cb677ebcd8ea2d145ec595c77e1912`。日期：2026-10-15。

## 当前行为

棋盘空点以绿、金、蓝表示当前行棋方的第一、第二、第三个候选。没有分析面板、排名文字、历史标亮、自选应手开关或额外确认按钮。点这些交叉点沿用原操作：鼠标点击落子，触屏先预选、第二次确认。

标记归属始终取实际下一落子棋色，和“我方 / 对方”角色、分析视角独立。每次落子立即作废上一局面的标记与请求，显示下一棋色的新结果。录入是否命中旧候选都不产生提示，不触发额外评分；AI 自动应手继续正常进行。旧版保存的自选偏好不再参与调度。

普通自由空盘立即提供天元及相邻两点作为起手参考；正式开局限定第一手天元时只有一个合法点。换色决定、提案、选案阶段由原流程处理，不显示普通落子提示。中盘的候选来自本局面引擎结果，只有一至两个有效候选时如实显示，不补造第三个。

## 计算与状态

- 复用原有单个 Worker、模型和搜索。普通自动落子同一次 MultiPV 3 搜索同时产出候选和最终应手，1 / 5 / 10 秒预算保持原设置，不增加独立候选搜索。
- 自适应的短候选筛选取三条变化，主要单主线深搜保留；后续首选可随深度更新，其余点仍属于同一棋盘的短候选。这里不显示分数，不把不同深度的分数拼成排名表。
- 后台片段从五候选 600 ms 改为三候选 400 ms。关闭后台思考后，新局面至多完成一轮有限分析。
- 已完成的一组候选可在自动搜索结束前流式显示；显示过程不结束或替换自动搜索。棋盘最多额外绘制三个小圆点，没有新增布局区域。
- 位置、棋色、规则、阶段、合法区域及请求 ID 共同限制结果。假想开局分支、旧请求、禁手、占用点、重复点和过浅结果不能覆盖当前提示。点位不变时不重画棋盘，更新合并至 100 ms。

取消了旧的 700 ms 单点复核、历史榜单快照及采用确认状态。两套 HTML 回到原棋盘布局，移除候选面板样式及运行时代码。原手动“推荐”按钮继续保留其原操作。
