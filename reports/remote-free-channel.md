# 免费手机连接验证

2026-10-17，网页版本 `2026.10.17.3`（v45），Windows / Intel i5-13400F，16 个逻辑核心。默认原生计算 15 线程，搜索哈希 256 MiB；测试搜索预算 1 秒。未重编译或替换 Rapfi 权重、搜索算法。

## 实现与使用

桌面「五目 · 手机远程连接」启动电脑服务和本机连接窗口。手机扫描窗口中的二维码，或打开复制的链接，确认「连接并使用」后继续使用 GitHub Pages 的当前棋盘。无需手机组网软件、服务账号或付款。

使用 Windows 自带 OpenSSH，经 Pinggy 免费节点的 443 端口建立加密通道，只转发 `127.0.0.1:4189` 的受控入口。独立 SSH 密钥与主机记录位于本机应用数据目录，不使用现有 SSH 配置、代理密钥或 GitHub 密钥；主机身份变化时停止连接。

免费通道单次最多 60 分钟，地址会改变；连接结束后启动器自动重建并更新本机二维码。手机需重新打开新链接，原棋盘保留。此模式不能提供永久地址或可用性保证。电脑和后台服务需要运行。[Pinggy 官方说明](https://pinggy.io/help/)

## 浏览器与访问边界

免费中转的浏览器确认页会截断跨站 WebSocket 升级。为这些明确识别的免费域名自动使用带认证的 HTTP 长轮询，仍转发同一引擎协议；其他地址继续走原有 WebSocket。应用请求使用官方支持的 `X-Pinggy-No-Screen` 请求头，不要求用户关闭浏览器安全检查。[官方接口说明](https://pinggy.io/docs/http_tunnels/screening/)

受控入口只提供 `/health` 和 `/gomoku`，没有文件、目录或管理接口。HTTP 会话要求精确网页来源、随机密钥、客户端 ID 和每次 Worker 独立的会话 ID；有长度、连接数、队列、长轮询和空闲回收限制。旧 Worker 的关闭和旧响应不会作用于新会话，完整棋盘同步、颜色、规则和合法点检查继续由原引擎层处理。

配对密钥只进入私用链接的片段和认证请求，不进入 HTTP URL 查询参数、棋谱或公开报告。二维码在本机生成；本机控制窗口另用独立令牌，限制回环 Host 和 Origin，刷新可保留当前窗口状态。二维码和进程状态不提交到仓库。

## 已验证

2026-10-18 补充：正式发布的 GitHub Pages 页面已分别在 Chrome 155.0.8059.80、Edge 135.0.3179.98 完成真实公网端到端验证；测试核对了线上远程模块与本地源文件一致，没有替换线上实现。两端均完成触屏确认、实际原生应手、思考中悔棋、旧应手废弃和连珠多候选，配置为 15 线程 / 256 MiB / 1 秒预算；单次应手的端到端耗时分别为 1689、1803 毫秒。这是连接验证样本，不是速度或棋力基准。明细见 `remote-public-qa.json`。

启动器补充处理了丢失进程记录和旧控制令牌：仅识别本项目确切 Node 启动命令；电脑服务可重建记录并复用，失效的手机窗口可重新启动，不会结束无关程序。已实测服务记录丢失后复用原进程、正常重复打开快捷方式，相关 5 项单元测试及源码校验通过。

同一时刻只允许一个对弈客户端；浏览器强制关闭时，最后的释放请求不一定送达，服务最多约 25 秒回收空闲连接。跨浏览器连续测试需留出释放时间；首次连续测试发生失败后，Edge 独立复测通过，未将失败计入通过结果。

- 333 项完整单元测试通过，语法、固定 WASM、补丁和连珠权重校验通过。
- 实际公网中转的候选版本在 Chrome 155.0.8059.80、Edge 135.0.3179.98 完成 15 线程 / 256 MiB 的真实原生应手、390px 触屏两次确认、悔棋和连珠三候选。不是只连到本机端口的模拟结果。
- 正式手机控制窗口验证二维码、复制调用、刷新保持、停止和重新建立新地址；未覆盖系统剪贴板。二维码宽度 420 像素。
- GitHub Pages 的旧缓存升级入口为远程模块增加版本参数，保证旧 v44 页面也能先加载支持免费通道的配对逻辑，再等待新缓存激活并恢复棋盘。

电脑端公网浏览器测试使用本机已有的 `127.0.0.1:7890` 出口代理，没有修改系统代理、DNS 或防火墙。尚未在第二台真实手机的移动网络上完成验收，不能将桌面触屏模拟称为真实手机测试。原生预算之外有网络延迟；没有由本次连接验证推导棋力或加速比。

最初的运行授权阻碍已通过用户选择「请求批准」解决。Cloudflare Quick Tunnel 虽成功获得临时地址，但在本机直连及现有代理下均未完成到边缘节点的 TLS 握手；实际采用了可连接的免费 Pinggy 通道。未注册或购买任何套餐，也没有通过改写审批策略绕过拦截。
