# 免费远程通道验证记录

2026-10-17，Windows，本项目独立检出目录 `ai-remote-native`。用户要求零费用，继续沿用云端界面，由开机电脑的原生引擎计算。

## 已完成

- 独立的本机受控入口，默认 `127.0.0.1:4189`，只接受 `/health`、`/gomoku` 与项目网页来源；不存在文件下载或管理接口。配对密钥通过 WebSocket 首帧认证，不进入 URL、日志或公开报告。
- 认证前不连接上游；限 4 个连接、32 KiB 请求、5 秒认证、心跳回收与发送积压限制。原生引擎仍维持单页独占、取消代际和合法落点检查。
- 原启动器同时管理计算服务与入口；本机停止服务后两个监听器均关闭。未更改原桌面项目或云端页面。
- 单元测试验证错误来源、错误密钥、受控路径、不能从入口调用管理接口、正确认证协议，以及启动后关闭两个监听器的生命周期。
- 实际原生测试经受控入口完成：15 线程、256 MiB、1 秒预算、3 个候选、合法落点、不改输入棋盘。此测试为本机链路，**不是互联网或真实手机测试**。
- 真实线上 GitHub Pages 页面经本机入口在 Chrome 155.0.8059.80、Edge 135.0.3179.98 完成配对、原生 15 线程应手和悔棋；没有关闭浏览器安全检查。该结果仍不等同于公网隧道测试。
- 全套 328 项测试通过；语法与固定网页引擎、补丁、连珠权重校验通过。

## 免费方案和已知阻碍

[Cloudflare Quick Tunnels 官方文档](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)说明无需账号或域名，可创建临时 HTTPS 地址；重启会换地址，没有可用性保证。适合先验证个人使用，不能承诺永久稳定入口。未注册账号、绑定付款方式或购买服务。

从 [cloudflared 官方 release 2026.10.1](https://github.com/cloudflare/cloudflared/releases/tag/2026.10.1) 下载 Windows amd64 工具。GitHub 发布的 digest 与本地 SHA-256 一致：`4d2490e74082c5d48dbfedaf92576fa5bd1702379ab88eb7faa0cfbe8dc891b6`。文件保存在本机应用数据目录，未提交二进制。

启动公网通道的操作被运行环境自动审批拒绝。改用上述只暴露认证对弈接口的入口后，启动仍被拒绝，返回 `blocked by policy`，没有具体规则或可用的批准入口。未改写审批策略，也未通过其他工具、包装器或供应商绕过拒绝。

因此当前**没有成功创建公网隧道，没有手机可用的公网地址或配对二维码**。网络延迟、手机移动网络可达性、隧道稳定性均未测量。电脑本机云端网页接原生计算的既有功能继续可用，不能把本次交付描述为手机远程连接已经完成。
