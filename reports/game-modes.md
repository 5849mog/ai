# 自定义摆局与简洁模式（v21）

两个模式由页首「菜单」进入，普通对战界面的操作、设置和分析继续默认显示。新增界面沿用和纸、木纹、墨色、苔绿与赭红；不新增外部字体、图片依赖或引擎构建。

## 自定义摆局

编辑器复制当前棋盘为独立草稿，可摆黑棋、白棋、擦除、撤回编辑、清空。下一手棋色与行棋者分别选择，允许任意黑白数量、白棋先续下以及 AI 执任一色。已成五和满盘不能作为起始局面。

只有「开始对弈」替换当前对局。进入编辑器会取消旧搜索、推荐和后台任务；取消编辑保留原棋盘、存档与悔棋记录，并恢复原来的行棋回合。开始时先验证，再统一应用局面与角色，避免部分替换。

起始棋子与真实续下分开记录。悔棋恢复到最近一次玩家续下之前，不删除起始棋子；AI 先续下的一手也不伪装成玩家可撤回的回合。分析记录包含起始局面身份，同样的续下序列不能复用另一份摆局的胜率与走势。

普通 JSON 继续使用版本 1；自定义 JSON 使用版本 2 的 `setup.board`、`setup.sideToMove` 和后续 `moves`。原存储键保留，旧记录无需迁移。SGF 用根节点 AB/AW/PL 保存起点，以真实颜色保存续下。导入仍在预览确认后替换，不支持中途改子、停着和让子规则。

BOARD 同步适配已对照固定版本 Rapfi 源码：起始实际颜色为黑，必要时用非连续 `-1,-1` 停着同步任意棋子数量与下一手。停着只存在于协议传输，不进入应用棋盘、手数、悔棋或导出。搜索、双候选推荐与后台短段共用此适配，原引擎发布文件及校验值未改。

## 简洁模式

只显示棋盘和两个按钮。新局沿用赭红主按钮；执色按钮直接在「你执黑」与「AI 执黑」间切换并重开，AI 执黑时自动开局。结果或重试状态放在新局按钮文字中，无独立分析、状态栏或菜单占据棋盘空间。

进入保留当前对局；网址 `?view=simple` 保留刷新后的显示模式。长按新局约 0.7 秒、浏览器/系统返回或 Esc 退出，退出保留对局。新局按钮内显示「长按返回」，执色按钮内显示「点击换边」。长按与拖动取消会抑制短按操作，避免退出时顺带重开。

棋盘按剩余宽高取最大正方形，按钮固定 54px 高，留出安全区域；窄屏边距为 2px。SVG 板边留白同步缩小，实际网格也随之放大。按钮与辅助文字分别为 16px、12px。保留原材质、焦点样式与触屏两次点击落子。

## 验证范围

`npm test` 的 60 项测试涵盖原有行为、自定义记录回放和格式往返、任意数量与下一手的协议同步、起始局面隔离。`npm run check` 检查 JavaScript 语法、原引擎与源码补丁 SHA-256。

`npm run test:modes` 使用真实 Rapfi WASM、无隔离头静态托管，检查编辑、取消、任意黑白数量、双方 AI 接局并以正确颜色成五、后台思考、推荐、完整回合悔棋、保存刷新、JSON/SGF 下载导入、思考期间编辑的取消与恢复。简洁模式用真实触屏事件检查长按退出，检查短按新局、直接换边、刷新续局、返回退出。八种视口检查两种模式和摆局编辑器的单屏布局；全新浏览器实例检查 v21 缓存与断网刷新后的摆局、模式和续局。

补充真实引擎探针验证了空盘指定白棋下一手的中心推荐；浏览器探针检查了直接进入 `?view=simple` 后系统返回，以及白方摆局的后台分析 → 推荐 → AI 应手 → 悔棋。

详细结果见 [game-modes-qa.json](./game-modes-qa.json)。截图在 `.cache/game-modes-qa/`。本次不重跑棋力基准，不用布局与交互检查推断棋力提升；浏览器实测为 Chromium，并未声称完成所有实体设备或 Safari 验收。
