# 网页调用电脑原生引擎

2026-10-17。基于最新 main `6fb78376161705240fb1c3ac7943650bbd366485`（v42）开发。新版网页已具备连珠禁手、五手两打、塔拉山口-10、自定义局面、截图导入、深入复盘、自适应深思和三色候选。因此复用网页完整功能，只替换搜索传输；没有将大量新界面搬回旧桌面版。

## 实现

- `remote-engine.js` 实现 Worker 兼容的 WebSocket 传输。保留原 `GomokuEngine` 的输入检查、请求代际、取消和合法落点验证；通过同一接口支持两页及现有开局/复盘搜索。
- `remote/native-runtime.js` 运行原生 AVX2 Rapfi 进程，直接复用当前网页的协议、搜索调度、推荐与完整评估收集。支持任意局面同步、1–32 候选、限定候选、平衡搜索、后台短段和禁手查询。
- 网页默认仍在浏览器计算。完整菜单和简洁「更多」有电脑引擎入口；验证地址和配对后刷新并恢复存档。连接中断保留棋盘，重试或明确切回网页计算。线程和搜索内存由电脑端决定，界面显示实际配置。
- `remote/start.cmd` / `start.ps1` 隐藏启动连接服务并打开网页配对窗口。启动链接只预填，用户确认才保存连接信息；密钥片段立即从地址栏移除。不覆盖已有桌面程序或快捷方式。

## 资源与访问边界

本次使用现有已校验原生可执行文件，SHA-256 `35b9e2686b46e44027ae821284a0d113a87485e10e8751f8fd3bed953faac8af`。Rapfi / Networks 提交与网页一致；LLVM-MinGW 20260616，带公开的 AVX2 非对齐读取修复。未重编译 WASM。复现构建及权重组装步骤见 [remote/README.md](../remote/README.md)。

服务只监听 `127.0.0.1`，不提供目录浏览或任意命令接口。默认来源限定为 `https://5849mog.github.io`，配对使用随机 32 字节密钥，认证前不创建引擎。密钥不在 WebSocket URL 或请求参数内。单一页面独占计算，同一标签页重载和取消可以替换其旧连接，另一页不能无提示抢占。消息、队列、时间、线程、内存和缓冲均有限制；连接关闭销毁其原生进程。未开始计算会话或页面已断开时，不持有原生模型进程；对局期间复用进程与缓存。

`/health` 只给允许的网页来源返回协议号，支持浏览器本地网络授权及旧 PNA 预检，不返回密钥和对局。`/shutdown` 只接受无 Origin 的正确密钥请求，用于本机启动器有序停止进程；网页和无认证请求不能调用。

## 尚未验证的网络环节

电脑本机的云端网页可用回环服务；手机的回环地址属于手机自己。电脑常见服务、进程、安装项和网络适配器中暂未发现可复用的组网/穿透工具，用户也尚未确认既有软件与 HTTPS 地址。此次未安装组网工具、未修改路由器或防火墙、未建立公开穿透通道。

因此不能声称真实手机外网已连通。后续已补充独立的受控入口 `127.0.0.1:4189`，跨设备 HTTPS/WebSocket 通道仅应指向该入口，不能直接指向原计算服务 `4188`。网页及引擎接口不必再重做。免费通道的当前验证和运行环境拦截情况见 [免费通道记录](./remote-free-channel.md)。电脑关机仍不能提供原生算力。多线程不保证线性提速，本次未给出新加速比、Elo 或实战胜率结论。
