# 云端续局与棋谱交付验收

2026-10-03；网页分支 `codex/cloud-game-records`，基于已发布 `74f30c1`。此次仅修改网页工作树，未修改 Windows 桌面分支或便携包。发布缓存版本 `250615-v8`；Rapfi / Networks / WASM 文件保持原发布校验值。

新增：同一浏览器自动续局（包括完整悔棋记录和待 AI 回合）、成五与整条长连的低对比度细线/外圈、JSON 与 SGF 导入导出。棋谱入口位于棋盘右上角，导入先展示真实棋盘预览并选择执色；确认才替换对局。保存/解析失败均保留可玩的当前局面，文件内容不能指定胜负或悔棋快照。推荐、悬停、待确认触点和旧搜索均不保存。

- `npm test`：44/44。包含四方向长连与同时成五、胜线清除、双方悔棋重建、终局和满盘和棋、SGF 转义/主线/格式拒绝、存储故障、过期响应与后台统计。
- `npm run check`：语法、引擎及源码补丁 SHA-256 校验通过；`git diff --check` 通过。
- `npm run test:records`：26/26，Chrome 154.0.8037.93、Edge 135.0.3179.98。完整结果：[record-qa.json](./record-qa.json)。时序边界使用确定性协议替身，应用、Worker、协议和规则均为实际代码。
- `npm run test:features`：21/21。真实四种 WASM 的后台短段、前台抢占与 Worker 重置；真实普通/隔离托管及白方对局；替身验证暂停、快速换色、胜负归属与触屏。
- `npm run test:recommendations`：18/18，同上两个浏览器。真实四种 WASM、双方 MultiPV 推荐、持久 Worker、无修改输入、`/plain/` 与 `/ai/`、资源零失败、断网刷新与推荐；替身验证取消和错误重试。完整结果：[recommendation-qa.json](./recommendation-qa.json)。
- 手机：390×844、320×568、844×390，两个浏览器均验证内联导入预览、触屏两次确认和悔棋；已有推荐布局验证一屏显示、控件不重叠。
- 视觉检查：实际浏览器截图检查桌面胜线、桌面及 320 像素导入预览、手机菜单，保持木纹和棋子材质。图片留于执行工作树 `.cache/record-qa/`。

## 后台思考验证

完整执行 12 个冻结局面 × 1/5 秒前台预算 × 3 次配对（72 对），各有独立 30 秒双候选参考；另测 12 个独立证明战术的开/关对照。单线程、256 MiB，严格顺序执行，总耗时 26.2 分钟。未重跑 40 局自对弈，也不推导胜率提升。

24/72 对开启时搜索深度提高，两档配对深度差中位数均为零。双方全部命中参考候选，战术均 12/12；1 秒时落点完全相同，5 秒时仅一对不同。响应时间未稳定改善。保留当前开关和默认值，不把后台思考作为显著增强棋力的宣传。设备、方法、逐局结果与原始统计见 [ponder-benchmark.md](./ponder-benchmark.md)。

续局使用浏览器本地存储，清除站点数据会清除记录；没有账号和跨设备同步。导出可保留文件、手动转到另一台设备。SGF 限制及文件格式见 [README](../README.md)。
