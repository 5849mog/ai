# 交互与入口审查：统一棋局流程

版本：2026.10.18.3（v48）。审查基线：`7186428`，2026-10-18。

## 审查结论

混乱的主要原因是首页与连珠页各自维护棋局、按钮、简洁界面和存档。后续功能优先加进连珠页，导致同名的「简洁模式」实际对应两套能力；用户需要跳页才能获得完整功能。继续增加入口会让问题更难理解。

本次将首页接入已有的完整棋局流程，删除旧 `app.js` 控制器。完整界面和简洁界面仅是同一局棋的两种显示。原 `renju.html` 地址保留兼容，恢复同一份当前棋局。规则、对局方式、当前执色与页面显示各有明确职责。

## 已发现并处理的问题

| 问题 | 原有影响 | 本次处理 |
| --- | --- | --- |
| 两个页面各有一套简洁界面 | 首页的简洁界面缺少正式开局能力，需再次跳页 | 两页加载同一控制器，一次进入完整的简洁界面 |
| 底部同一位置的按钮在不同页面分别换色或选规则 | 不清楚是否会立即重开、切色或影响当前棋局 | 统一为「对局」，打开同一个设置草稿，确认开始新局才应用 |
| 简洁界面新局暗中把手动记录改成 AI 附身 | 用户没有选择，AI 却可能接管落子 | 新局保留当前规则与对局方式 |
| 长按新局又负责退出简洁界面 | 操作隐藏，容易与重新开局冲突 | 新局只重开；更多中提供明确的「完整界面」 |
| 两个地址独立保存当前棋局 | 跳页后看似丢棋或恢复错误的一局 | 共用当前局；首次升级选择最近有效归档对应的旧局，另一个旧局保留在最近对局 |
| 旧棋谱恢复需要跳到另一个应用页面 | 恢复过程中显示和按钮意义再次变化 | 旧 JSON、SGF 与完整连珠记录在当前界面直接恢复；保留导入预览、取消和确认 |
| 展开更多参与布局计算 | 小窗口棋盘突然缩小，控件位置跳动 | 改为可收起、可滚动的临时浮层，不改变棋盘尺寸；点外部或 Escape 收起 |
| 多处出现重试、复盘等重复入口 | 画面重复，状态难以同步 | 重试复用已有入口；完整界面终局复盘保留在新局旁 |
| 手动记录的摆局与截图中仍问「AI 来走」 | 用户容易误判谁负责下一手 | 手动记录隐藏 AI 执行者选择，双方继续手动录入 |
| 对弈时仍提示「录入对方」 | 提示与用户真正需要做的动作不一致 | 按手动记录、AI 代下、AI 对弈分别显示当前动作 |
| 对弈开局只有 AI 操作时悔棋仍可点 | 撤完又自动重下，表现像按钮失效 | 没有可撤回的己方操作时禁用悔棋 |
| 非手动记录界面显示不可用的执色下拉框 | 与阶段内换色、选角色入口混淆 | 执色由正式流程决定；仅手动记录保留「分析视角」，并且它不改变棋局 |

## 整理后的操作规则

| 入口 | 稳定含义 | 对当前棋局的影响 |
| --- | --- | --- |
| 新局 | 按当前规则、当前方式重新开局 | 保存旧局后新开；重新选择本局角色 |
| 对局 / 对局设置 | 选择规则和对局方式 | 修改草稿不影响当前局；「开始新局」才应用 |
| 悔棋 | 撤回上次实际操作 | 自动应手与触发它的操作成组撤回；候选、选案、换色按流程撤回 |
| 推荐 | 查看当前操作或落点的建议 | 不直接执行；AI 自动落子独立工作 |
| 更多 | 思考预算、后台思考及较少使用的工具 | 调整预算不重开棋局；截图、摆局均需确认 |
| 完整界面 / 简洁界面 | 改变界面显示 | 不改变棋局、规则、角色或 AI 负责方 |
| 阶段按钮 | 当前阶段的角色、换色、十打或选案 | 只在相关阶段出现，继续使用棋盘上沿或侧边的留白 |
| 最近对局 | 继续或查看已有记录 | 在当前页面恢复，复盘不写入当前棋局 |

规则共有四种：无禁手、禁手自由开局、五手两打、塔拉山口-10。对局方式共有三种：AI 替我下（外部对局）、手动记录双方、与 AI 对弈。二者在同一设置里选择，完整与简洁共用。

没有旧记录时，首页继续默认无禁手与 AI 对弈；旧连珠直达地址继续提供原来的五手两打外部对局起点。一旦保存过当前局，两地址就恢复同一局，地址不再代表另一套应用。

简洁界面常驻四个按钮和一个更多入口。三个推荐点仍直接显示在棋盘上，跟随实际下一方更新。阶段按钮只在需要操作时占用独立留白。没有增加常驻侧栏、候选分析面板或新的导航层级。

## 旧数据与升级

- 两份旧当前局都先校验；存在有效时间信息时选最近更新的一局，没有时间信息时优先原完整连珠记录。
- 原无禁手记录不删除、不覆写。非当前局归档保留；已有归档复用原 ID，保留收藏与时间，避免重复。
- 首次统一后写入迁移标记，下一次刷新不再重新挑选旧局，防止「新局后又恢复旧棋」。
- 损坏的完整记录另留原始备份；有效旧记录仍可迁移。派生胜率历史只在棋子、起始局面与执色完全一致时复用。
- 旧 JSON v1/v2 与 Freestyle SGF 可导入；正式连珠 JSON 保留换色、角色、候选和部分提案。SGF 只能保留实际棋子，不能替代完整正式开局记录。
- 缓存版本更新为 v48，新增兼容模块并移除旧控制器。固定模型继续复用，不因界面更新重新下载权重。

## 后续维护约束

新增规则应进入现有对局设置与状态机；新增阶段操作应进入现有棋盘旁控件。完整与简洁必须共用动作，入口不同也不能改变含义。较少使用的工具继续放在更多或菜单里，避免扩充底部常驻按钮。按钮文案应说实际动作，并与真实执行方、棋色保持一致。

下一轮如继续调整，应优先观察用户是否还会误判「AI 替我下」和「与 AI 对弈」，以及实体手机极短窗口内的设置浮层；有具体复现后再修改，不预先堆积更多开关。
