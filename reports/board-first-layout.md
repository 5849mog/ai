# 棋盘优先的响应式布局（v14）

宽屏棋盘取消 700px 固定上限和 `100dvh - 316px` 的高度锁定，按 `30vw + 35dvh` 同时随宽、高增长，并受可用容器宽度约束。桌面操作区集中在 272–300px 的侧栏，品牌、棋谱入口与页脚沿整个对弈区域对齐。手机竖屏保留原有接近满宽的棋盘，横屏保留完整棋盘的高度适配。

## 排版

- 执色、思考时间统一为两列，标签 12px，选择器 14px；后台思考独立一行。
- 局势判断、胜率和走势处于搜索统计之前；深度、评分、节点、速度保持显示，排在分析区末尾。
- 所有界面状态文字至少 12px，包括第 N 手、胜率图例、走势轴标签和页脚。走势标签改为 HTML 排版，字号不受 SVG 的整体缩放影响。
- 取消胜率条宽度动画；保留木纹、纸纤维、缎面棋子、原配色、提示文案和现有功能。
- 操作按钮、下拉框和后台思考标签保持至少 44px 高的点击区域。短屏允许纵向滚动承载辅助信息。

## 测量

以下面积占比为可见棋盘 SVG 的面积除以完整视口面积，排除木框和其他界面。

| 视口 | v14 棋盘边长 | 棋盘面积占比 |
| --- | ---: | ---: |
| 320 × 568 | 308px | 52.2% |
| 390 × 844 | 378px | 43.4% |
| 844 × 390 | 318px | 30.7% |
| 1280 × 900 | 691px | 41.4% |
| 1440 × 900 | 739px | 42.1% |
| 1920 × 1080 | 946px | 43.2% |

同一浏览器实测 v13 在 1440 × 900 下的棋盘边长为 576px、面积占比 25.6%；v14 提升到 739px、42.1%。1440 × 900 和 1920 × 1080 的完整桌面布局无需纵向滚动。
